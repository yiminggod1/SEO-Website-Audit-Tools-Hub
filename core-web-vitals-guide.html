Core Web Vitals are user-experience signals. LCP describes loading performance, INP describes responsiveness to interaction, and CLS describes visual stability. Google recommends evaluating these metrics at the 75th percentile of real-world usage when field data is available.

01

LCP

Good is 2.5 seconds or less. Investigate large hero images, slow server responses, render-blocking work and oversized resources when it is slower.

02

INP

Good is 200 milliseconds or less. Look for long JavaScript tasks, expensive event handlers and UI work that blocks the main thread.

03

CLS

Good is 0.1 or less. Reserve space for images and embeds and avoid layout shifts caused by late-loading content.

04

Why the lab report still helps

A Lighthouse run gives reproducible diagnostic evidence, but it is not a substitute for field data. Use the live audit to find likely causes, then use Search Console or other field data to understand actual users.
