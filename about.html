LIMITS

Know what a browser tool can and cannot see.

Static browser checks cannot reliably bypass cross-origin restrictions, crawl private pages, or inspect every server-side response header. Where remote access is unavailable, the tool asks you to paste the relevant HTML or response headers instead of pretending it performed a crawl.
