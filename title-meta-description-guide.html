Title and meta description
write for the page, not the character counter.

A title should tell a person what the page is about. A meta description should help a searcher understand what they will find after the click. Length checks can be useful as diagnostics, but they are not guarantees about how Google will display a snippet.

A title should tell a person what the page is about. A meta description should help a searcher understand what they will find after the click. Length checks can be useful as diagnostics, but they are not guarantees about how Google will display a snippet.

01

Start with the page promise

Write the title around the actual subject of the page. Avoid vague brand-only titles on pages where the topic is the main reason someone clicks.

02

Use descriptions as summaries

Describe the page accurately, include the key action or information, and avoid repeating a keyword list. Search engines may choose different snippets when the page content better answers the query.

03

Audit the whole cluster

Compare sibling pages. Near-identical titles across dozens of pages make it harder for users to distinguish pages and often indicate that the information architecture needs work.

04

Use the tools

Run Meta Tag Analyzer for markup, then use SERP Preview to check the editorial presentation. Re-test after deployment rather than assuming the source file is the live result.
